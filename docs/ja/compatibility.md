# 対応状況

[English](../en/compatibility.md)

[READMEの機能](../../README_ja.md#機能)について、使える範囲と必要な構成を確認するための概要です。
文字や画像の制御列をboxrig coreで解釈し、boxrig UIで表示や入力を組み込めます。
まず機能の概要を確認し、次に利用する環境の条件へ進んでください。
制御列の詳細、OSの最低条件、検証環境は末尾の参照先へまとめています。

## 対応表の読み方

「対応」は公開APIまたは付属実装で扱う機能を指します。
OS、描画方式、入力メソッド、アプリケーション側の接続によって利用条件が変わります。
コード上の最低条件と、実行して確認した環境は同じではありません。

## 端末機能の概要

文字列の取得・検索や入力列への変換はcoreだけでも利用できます。
フォントによる表示、未確定文字や候補、選択範囲の装飾にはUIを使います。
シェルとの通信や、タイトル・通知などのOS操作はアプリケーション側で接続します。

| 用途 | 対応する内容 | 詳細 |
| --- | --- | --- |
| 文字と制御 | UTF-8、結合文字、絵文字、ANSI色、RGB色、装飾、点滅、画面と履歴 | [制御列](./reference/terminal-sequences.md) |
| 入力 | 改行設定、Shift_JIS変換、キー設定、Kitty keyboard、貼り付け、マウス、フォーカス | [送受信設定](./terminal-io.md) |
| 本文の利用 | スナップショット、選択、完全一致検索、出現監視、範囲を制限した正規表現認識 | [文字列](./text.md) |
| 画像 | Kitty graphicsの静止画、配置、外部転送、アニメーション | [画像仕様](./reference/graphics.md) |
| ホスト連携 | タイトル、リンク、クリップボード、通知、外部画像の要求 | [ホスト連携](./host-integration.md) |
| 見た目 | フォント、拡大、背景、透過、色補正、カーソルと選択範囲 | [文書目次](./index.md) |

## 環境別の違い

UIはX11、GTK 3、GTK 4、native Wayland、Win32へ組み込めます。
標準の描画に加え、任意のOpenGLとWindowsのDirect3D 11を選べます。
coreだけならウィンドウや描画ライブラリは不要です。

背景効果、候補ウィンドウ、クリップボード、アクセシビリティはOS側の機能にも依存します。
[環境別対応表](./reference/platform-support.md)で利用条件を確認してください。

## IMEの周辺文字列と同期編集

未確定文字の表示と通常のIME確定文字の送信に対応します。
アプリケーションが編集文書を登録した場合は、周辺文字列の参照や同期編集も利用できます。

周辺文字列を渡すだけの接続と、編集要求を確定できる所有者の接続は異なります。
GTK 3／4、native Wayland、XIMでは、編集所有者を接続した場合に文書の削除・確定を一度だけ実行します。
Win32では周辺文書や再変換を扱いますが、通常のIME確定はPTYへの送信を継続します。
共通の設定関数があるだけで全環境の編集経路が同じになるわけではありません。

[入力とIME](./input-ime.md)に接続手順、[環境別対応](./reference/platform-support.md#ime通知クリップボードアクセシビリティ)に入力メソッドごとの条件を記載しています。

## Windowsの層別最低要件

coreと通信の基礎部分、文字描画、GPU描画、ConPTYでは必要なWindowsの版が異なります。
古いOS向けにcoreをリンクできることから、端末デモ全体も動作すると判断しないでください。

SDKのi686基礎部分はWindows 2000、amd64はWindows XP x64を基準としています。
標準UIにはDirectWrite、D3D11にはDirect2D 1.1などが必要で、OS付属ConPTYはWindows 10 1809以降です。
詳しい版と確認の範囲は[Windowsの層別条件](./reference/platform-support.md#windowsの層別条件)を参照してください。

## 通知の対応

OSC 99のタイトル、本文、識別子、表示条件、緊急度を解析します。
付属端末は全5環境で通知プロバイダーへ接続しますが、既定では表示を拒否します。
`BOXRIG_ALLOW_NOTIFICATIONS=1`で起動した場合だけ許可し、頻度も制限します。

通知の解析能力の問い合わせは、OSの表示許可を表しません。
詳細は[制御列](./reference/terminal-sequences.md#osc-99の通知)と[環境別対応](./reference/platform-support.md)を参照してください。

## 未対応

sixelとiTerm2の画像、プリンター出力には対応していません。
GTK 3／4は端末のroleに加え、既定では無効な本文公開を提供します。有効にすると、表示中の本文、caret、選択範囲、文字属性と変更通知を支援技術から取得できます。
GTK 4の本文座標取得と、支援技術からのcaret・選択変更は提供しません。設定方法と範囲は[GTK](./platforms/gtk.md#支援技術から本文を取得する)を参照してください。

正規表現認識には構文と処理量の制限があり、完全一致検索にUnicode case foldingや正規化の検索オプションはありません。
過去の[検索変換の試作](./search-capability-prototype.md)を公開機能とは扱いません。
