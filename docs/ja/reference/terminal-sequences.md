# 制御シーケンスと入力プロトコル

[English](../../en/reference/terminal-sequences.md)

文字を赤くする、カーソルを動かす、画面を切り替えるといった操作を、端末へ送る制御シーケンスで指定できます。
この文書は、boxrig coreが解釈する制御列と、入力や問い合わせに応じて返すバイト列の対応表です。

例えば[READMEの赤い文字を表示する例](../../../README_ja.md#アプリケーションへ端末表示を加える)では、SGRによる色指定を使っています。
短い出力で表示を試す場合は[boxrig_emitter](../boxrig_emitter.md)、APIから改行や文字コードを設定する場合は[送受信設定](../terminal-io.md)を参照してください。

## 対応プロファイルと表記

boxrigは、ECMA-48、DEC VT、xtermを基本に、表に示したKittyの拡張を扱います。
各仕様の全機能を実装しているという意味ではありません。
表にない指定を必要とする場合は、公開APIとテストで対応を確認してください。

| 表記 | バイト列・意味 |
| --- | --- |
| ESC | `0x1b` |
| CSI | `ESC [` |
| OSC | `ESC ]` |
| DCS | `ESC P` |
| APC | `ESC _` |
| ST | `ESC \` |
| Ps、Pm | 数値パラメーター、パラメーター列 |

列中の空白は区切りです。
ただし`CSI Ps SP q`のSPは実際の空白バイトです。
制御列の座標は通常1から始まり、C APIの行・列は0から始まります。
仕様の出典は[xtermの制御列](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html)、[Kitty keyboard](https://sw.kovidgoyal.net/kitty/keyboard-protocol/)、[Kitty desktop notifications](https://sw.kovidgoyal.net/kitty/desktop-notifications/)です。

## 文字とC0

既定ではUTF-8を逐次解釈します。
分割して受信した文字は次回の入力まで保持し、不正な列は置換文字として扱います。
結合文字と絵文字を文字クラスター単位で保持し、1クラスターの上限は4,096バイトです。
曖昧幅は1列または2列を選べます。
Shift_JISとの変換や互換設定は[送受信設定](../terminal-io.md)、フォントによる整形は[フォントと配置](../fonts-and-layout.md)で説明しています。

| 入力 | 動作・条件 |
| --- | --- |
| BEL | ベルをホストイベントとして通知 |
| BS | カーソルを1列戻す。文字は消さない |
| HT | 次のタブ位置へ移動 |
| LF、VT、FF | 改行。CRを伴うかは受信改行設定とモードによる |
| CR | 行の先頭へ移動 |
| SO、SI | G1、G0の文字集合へ切り替え |
| CAN、SUB | 解析中の制御列を中止し、通常入力へ戻る |

## ESCとCSI

| 指定 | 動作 | 条件 |
| --- | --- | --- |
| `ESC 7`、`ESC 8` | カーソルと属性を保存・復元 | 原点、折り返しなどの状態も含む |
| `ESC D`、`ESC E`、`ESC M` | 下へ移動、次行、逆方向へ移動 | 必要ならスクロール |
| `ESC H` | タブ位置を設定 | 現在列 |
| `ESC ( 0`、`ESC ) 0` | DEC特殊文字集合をG0、G1へ設定 | SO／SIで選択 |
| `ESC ( B`、`ESC ) B` | ASCIIをG0、G1へ設定 | 同上 |
| `ESC =`、`ESC >` | キーパッドのapplication／通常モード | 送信キーへ反映 |
| `ESC c` | 端末をリセット | RIS |
| `CSI Ps A/B/C/D` | 上・下・右・左へ移動 | 省略値と0は1 |
| `CSI Ps E/F/G/d` | 次行・前行・絶対列・絶対行 | 省略値と0は1 |
| `CSI row ; col H/f` | 行列へ移動 | 原点モードと余白を反映 |
| `CSI Ps @/P/X` | 文字の挿入・削除・消去 | ワイド文字を分断しない |
| `CSI Ps L/M` | 行を挿入・削除 | スクロール領域内 |
| `CSI Ps S/T`、`CSI Ps ^` | 上・下へスクロール | `^`も下方向 |
| `CSI Ps b` | 直前の文字を繰り返す | REP |
| `CSI 0 g`、`CSI 3 g` | 現在位置・全てのタブを解除 | TBC |
| `CSI Ps J`、`CSI Ps K` | 画面・行を消去 | 0は後方、1は前方、2は全体。`CSI 3 J`は履歴の消去 |
| `CSI ? Ps J/K` | 保護していないセルを消去 | 選択消去 |
| `CSI top ; bottom r` | 上下の余白を設定 | 不正な範囲は採用しない |
| `CSI left ; right s` | 左右の余白を設定 | モード69が有効なとき |
| `CSI s`、`CSI u` | カーソルを保存・復元 | `s`は左右余白モードが無効なとき |
| `CSI ! p` | ソフトリセット | DECSTR |
| `CSI Ps " q` | セル保護の設定 | 1で有効、0／2で解除 |
| `CSI 22 ; Ps t`、`CSI 23 ; Ps t` | タイトルの保存・復元要求 | 0は両方、1はアイコン、2はウィンドウ。保存先はホスト |
| `CSI 8 ; rows ; columns t` | [行列数変更のホスト要求](../host-integration.md#行列数の変更要求を扱う) | 各軸の省略は維持、0はディスプレイ寸法。許可と実寸はホストが決定 |

プリンター制御の`CSI 0/4/5 i`とmemory lock／unlockは受理して何も行いません。
未知の指定からは、終端を読んだ後に通常の文字表示へ戻ります。

## モード・画面・スクロール

通常モードは`CSI Ps h/l`、DEC private modeは`CSI ? Ps h/l`で有効・無効にします。

| モード | 利用者から見える動作 |
| --- | --- |
| 4、20 | 挿入、改行モード |
| ?1、?66 | カーソルキー、キーパッドのapplication mode |
| ?5、?6、?7 | 画面反転、余白を原点とする移動、自動折り返し |
| ?12、?25 | カーソルの点滅、表示 |
| ?47、?1047、?1048、?1049 | alternate screen、消去を伴う切り替え、カーソル保存、保存と画面切り替え |
| ?69 | 左右余白 |
| ?9、?1000、?1002、?1003 | X10、ボタン、ドラッグ、全移動のマウス追跡。互いに排他 |
| ?1004 | フォーカスの送信 |
| ?1006、?1016 | SGRのセル座標、物理ピクセル座標。互いに排他 |
| ?1007 | alternate screenでホイールをカーソル上下キーへ変換 |
| ?1034 | 8-bit Meta |
| ?2004 | bracketed paste |
| ?2026 | 同期更新 |

1007は既定で無効です。
マウス追跡が無効なalternate screenで縦ホイール1段を上下キーへ変換し、DECCKMを反映します。
この変換にはKitty keyboardや独自キー設定を使いません。
ソフトリセットと画面切り替えでは保持し、RISで解除します。

同期更新中も入力の解析は続け、UIは最後に確定した画面を表示します。
解除されない場合は開始から1,000 msで回復します。
再設定やリサイズで期限を延ばしません。
時計の供給とフレーム処理は[点滅](../blinking.md)と同じアニメーション基盤を使います。

primary screenの履歴とalternate screenの内容は独立しています。
primary画面で全幅を対象に、画面上端から上へスクロールする場合だけ、その行を履歴へ保存します。スクロール領域の下端が固定フッターの上にある場合も同じです。
画面上端を含まない領域、左右の一部だけの領域、alternate screenのスクロールは履歴を増やしません。
リサイズ時は折り返し情報を使って本文を並べ直します。
履歴、選択、論理行の位置を扱うAPIは[文字列の取得・選択・検索](../text.md)を参照してください。

## SGRとカーソル

`CSI Pm m`は以後の文字の属性を変更します。
描画方式ごとの色の変更は[表示色の補正](../color-filters.md)へ分けています。

| 指定 | 属性・解除 |
| --- | --- |
| 0 | 全属性を初期化 |
| 1、2、3 | 太字、淡色、斜体。22で太字と淡色、23で斜体を解除 |
| 4、21、4:1〜4:5 | 単線、二重線、単線／二重線／波線／点線／破線の下線 |
| 24、4:0 | 下線を解除 |
| 5、6 | 遅い点滅、速い点滅。25で両方を解除 |
| 7、8、9 | 反転、非表示、取り消し線。27、28、29で解除 |
| 30〜37、40〜47 | 基本8色の前景・背景 |
| 90〜97、100〜107 | 明るい8色の前景・背景 |
| 38、48、58 | 前景・背景・下線の拡張色。`5;n`の索引色、`2;r;g;b`のRGB色。コロン区切りも対応 |
| 39、49、59 | 前景・背景・下線色を既定へ戻す |

DECSCUSRの`CSI Ps SP q`は、0／1が点滅矩形、2が固定矩形、3／4が点滅／固定下線、5／6が点滅／固定縦棒です。
UIで上書きしたカーソル設定との関係は[カーソルと選択範囲](../decorations.md)、点滅周期は[点滅](../blinking.md)で説明しています。

## OSC・DCS・APC

OSCはBELまたはSTで終わります。
DCS、APC、PM、SOSはSTで終わり、内部のBELを終端とは扱いません。
CAN／SUBは途中の列を中止します。
8-bit C1のDCS、APC、STには対応していません。

| 指定 | 対応する内容・条件 |
| --- | --- |
| OSC 0／1／2 | 両タイトル／アイコン名／ウィンドウ名の変更要求 |
| OSC 4／104 | パレットの設定・問い合わせ／解除 |
| OSC 7 | 作業ディレクトリをホストへ通知 |
| OSC 8 | ハイパーリンク。`id`とURIを保持し、履歴とリサイズにも追従 |
| OSC 10／11／12 | 既定の前景・背景・カーソル色の設定・問い合わせ |
| OSC 110／111／112 | 既定色の変更を解除 |
| OSC 52 | クリップボードの読み書き要求 |
| OSC 99 | 後述のデスクトップ通知 |
| DCS `$q` | 状態文字列の問い合わせ。次節を参照 |
| APC `G` | Kitty graphics。[画像仕様](./graphics.md)を参照 |

色は各成分1〜4桁の`#RGB`形式、または`rgb:R/G/B`形式です。
色名には対応しません。
問い合わせの`?`に対し、`rgb:rrrr/gggg/bbbb`を返します。

OSC 8のリンクはSGRとは独立し、coreは自動で開きません。
URIとidの合計保持量は既定1 MiBで、登録できない指定ではリンクを有効にしません。
開く操作と許可は[ホスト連携](../host-integration.md)の責任です。

OSC 52は`c,p,q,s,0〜7`の選択先を受理し、省略時は`0`です。
書き込みは厳密なBase64として読み、不正な内容は空の書き込み要求になります。
`?`は読み取り要求です。
既定の上限は32 KiB、設定を0にすると無効です。
ホストは要求を取り出してから一度だけ完了させます。
読み取りの応答を待つ間は、後続入力が応答を追い越さないよう送信順序を保持します。

### OSC 99の通知

| 項目 | 受理する値 |
| --- | --- |
| `p` | `title`、`body`、`?`。省略時はtitle |
| `i` | 英数字と`_+.-`からなる最大128文字の識別子。`0`は識別子なし |
| `d` | 0で分割を継続、1で確定。省略時は1 |
| `e` | 0でUTF-8、1でBase64 |
| `f`、`t` | Base64のアプリ名、通知種別。種別は最大16個 |
| `o` | `always`、`unfocused`、`invisible` |
| `u` | 0、1、2の緊急度 |

本文のCRLFとCRはLFへそろえ、LFとタブ以外の制御文字を拒否します。
タイトル、アプリ名、種別では制御文字を認めません。
タイトルが空なら本文をタイトルへ使い、両方が空なら通知しません。
UTF-8断片は2,048バイト、Base64断片は4,096バイトまでです。
組み立て中の通知は既定16件、1件32 KiBまでで、両設定を0にすると問い合わせも無効になります。

問い合わせへの能力応答は`p=title,body,?:o=always,unfocused,invisible:u=0,1,2`です。
これは端末の解析能力であり、OS側の表示許可ではありません。
閉じる操作、存続確認、ボタン、アイコン、操作結果の報告、音、期限には対応しません。
未知のメタデータキーは無視します。
実際の通知条件は[環境別対応](./platform-support.md)を参照してください。

## 問い合わせと応答

| 問い合わせ | 応答 |
| --- | --- |
| `CSI 5 n` | `CSI 0 n` |
| `CSI 6 n`、`CSI ? 6 n` | 現在行列を`CSI row ; col R`、private形式で返す |
| `CSI ? 15/25/26/75/85 n` | それぞれ`?10n`、`?20n`、`?27;1;0;0n`、`?70n`、`?83n` |
| `CSI c`、`CSI > c` | `CSI ? 62 ; 6 ; 22 c`、`CSI > 1 ; 0 ; 0 c` |
| `CSI > 0 q` | DCS、`>`、縦棒、`boxrig`、STの順に返す |
| `CSI Ps $ p`、private形式 | `CSI Ps ; Pm $ y`。Pmは1が有効、2が無効、0が未知 |
| `CSI 14 t`、`CSI 16 t` | 設定済みの描画領域・セルの物理ピクセル寸法 |
| `DCS $q selector ST` | 対応する指定は`DCS 1$r state ST`、未対応は`DCS 0$r ST` |

DECRQSSのselectorは`m`、`r`、`s`、`SP q`、`"q`です。
不正な列、途中で中止した列、上限超過は応答しません。
送信キューが満杯の場合は、応答を二重生成せずに再試行できます。

## キー・貼り付け・マウスの送信

`send_key()`は論理キー、修飾、押下／反復／解放と関連文字列を受け取ります。
legacy形式ではF1〜F20にxtermの列、F21〜F35やメディアキーなどにKittyの機能キー番号を使います。
反復は押下と同じ列、解放は通常送信しません。
Alt付きの文字にはESCを前置します。
Control付きのASCII文字は対応するC0／DELへ変換し、Shift付きでは実際の論理記号を優先します。
IME確定、貼り付け、`send_text()`にはこのキー変換を適用しません。

Kitty keyboardでは`CSI ? u`で照会し、`CSI = flags ; 1/2/3 u`で置換／追加／解除します。
`CSI > flags u`で保存して設定、`CSI < count u`で復元します。
primaryとalternateに独立した16段のスタックがあり、超過時は最古を捨てます。
RISは両方を初期化します。

| フラグ | 動作 |
| --- | --- |
| 1 | 曖昧なキー列を区別 |
| 2 | 反復と解放の種類を報告 |
| 4 | Shift適用後と基本配列のキーを追加 |
| 8 | 文字、機能キー、修飾キーを全て報告 |
| 16 | 8との併用で関連文字列を付加。解放時は付加しない |

bracketed pasteは`CSI 200 ~`と`CSI 201 ~`で囲みます。
開始時の設定を終了まで保持するので、途中のモード変更でも対が崩れません。
ESCを含む貼り付け断片は終端の偽装を防ぐため拒否します。
focus reportingはフォーカス取得を`CSI I`、喪失を`CSI O`で送信します。

legacy mouseは`CSI M`にボタンと座標を続け、0基点の行列が223以上なら`LIMIT_EXCEEDED`です。
1006は1基点の10進セル座標、1016は内容領域を原点とする1基点の物理ピクセル座標です。
1016では領域外の負値や寸法を超える値も表せます。
SGR形式の押下・移動は`M`、解放は`m`で終わります。

1イベントの追加は原子的です。
`WOULD_BLOCK`ならキューを送信してから同じイベントを再試行します。
キー設定の優先順位と文字コード変換は[送受信設定](../terminal-io.md)を参照してください。

## terminfoと制限

付属端末は`TERM=xterm-256color`を既定とし、`BOXRIG_TERM=xterm`も選べます。
独自のterminfoは配布していません。
この名前だけでxtermの全拡張への対応を判断しないでください。

CSIは32パラメーター、intermediateは4バイトまでです。
超過したCSIはfinal byteまで読み捨てます。
制御文字列は既定1 MiBまでで、超過時は終端まで読み捨てて回復します。
未知のDCS／APC／PM／SOS、sixel、iTerm2画像は描画しません。
容量と状態の定義は[terminal.h](../../../include/boxrig/terminal.h)、実際の受理条件は[coreテスト](../../../tests/test_terminal.c)から確認できます。
