# 任意文字列の正規表現照合

`boxrig/regex.h`は、端末やGUIを生成せずにUTF-8の文字列を照合するAPIです。
`libboxrig.a`へリンクして使います。画面の文字列認識器と同じ文法・一致規則で照合できます。

## CLIで試す

次の例は、標準入力から最左最長の一致を探すコマンドです。

```sh
make boxrig-regex
printf 'zaaa' | build/boxrig-regex 'a|aa' 0 1
```

結果の`match 1 3`は、入力のバイト位置1から3の手前までの一致を示します。
`work`は照合に使った処理量です。最後の引数を1にすると、処理を1単位ずつ再開します。
開始バイト位置の既定値は0、1回の処理量の既定値は4096です。
終了値は、一致なら0、不一致なら1、入力やパターンのエラーなら2となります。

NULを含むパターンには`--pattern-file FILE`を使います。
入力中のNULも照合対象です。CLIの容量は、パターンが64KiB、入力が1MiBです。
これらを超えた場合はエラーになります。

## APIで使う

`boxrig_regex_limits_default()`で容量設定を作り、`boxrig_regex_compile()`へパターンとバイト長を渡します。
取得したコンパイル結果は、不変の`boxrig_regex_program`です。
失敗時は`boxrig_text_regex_diagnostic`のコードと`pattern_offset`で原因と位置を確認します。
診断型は画面認識器と共通です。

照合には`boxrig_regex_matcher_create()`を使います。
入力、バイト長、開始バイト位置を指定すると、入力を検証してコピーした照合器を取得できます。
作成時の検証とコピーは、入力長に比例した時間がかかる同期処理です。
不正なUTF-8や開始位置は、返されたエラー位置で確認してください。

`boxrig_regex_matcher_resume()`へ正の処理量を渡すと、照合が進みます。
`IN_PROGRESS`の間は同じ照合器を再開します。
`MATCH`では`start`から`end`の手前までが一致範囲となり、位置は元の入力のバイト単位です。
`NOT_FOUND`では照合が終了しています。終了した照合器は再開できません。

照合器は入力とコンパイル結果を保持するため、作成後は呼び出し側の入力を変更・解放できます。
呼び出し側のプログラム参照も`boxrig_regex_program_destroy()`で解放できます。
複数の所有者でプログラムを保持するときは、`boxrig_regex_program_retain()`を使ってください。
取得した参照ごとに解放が必要です。
同じプログラムの共有操作と参照数の変更は、呼び出し側で直列化してください。
照合器自体は`boxrig_regex_matcher_destroy()`で解放します。

## 文法と一致規則

リテラル、`.`、文字クラス、グループ、`|`、`?`、`*`、`+`、`{m}`、`{m,n}`、`^`、`$`を使えます。
メタ文字のエスケープ、`\n`、`\r`、`\t`、`\u{hex}`も使用可能です。
`\d`、`\s`、`\w`はASCIIの文字クラスです。
空文字と一致する式、後方参照、先読み・後読み、連続した量指定子には対応していません。

文字をUnicodeスカラー単位で照合し、一致全体の両端を拡張書記素境界に限定します。
たとえば`a`と結合アクセントを組み合わせた文字に、`.`だけでは一致しません。
開始位置が書記素の途中なら、次の書記素境界から探します。
UTF-8の継続バイトを開始位置に指定した場合はエラーです。

`^`と`$`は入力全体の先頭・末尾を指します。開始位置を変えても、先頭の意味は変わりません。
`.`は改行にも一致し、正規化や大文字・小文字の変換は行いません。
同じ開始位置に複数の一致がある場合は最長のものを返します。

パターン長、状態数、反復回数、入力長に個別の容量を設定できます。0を無制限の意味では使いません。
固定したパターンでは、不一致の場合も総照合処理量は入力長に比例します。
処理量の1単位は、状態の訪問、遷移、または入力位置の確認です。
文字クラスの訪問では、そのクラスに含まれる範囲を比較します。
